# 🤖 Chatbot

Chatbot i thjeshtë me ndërfaqe grafike — përgjigjet automatikisht përshëndetjeve dhe pyetjeve bazë. Ndërtuar me Tkinter (Python).

## 🚀 Si ta hapësh

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë.

## 📁 Struktura

```
Chatbot-Tkinter/
  demo/Chatbot.py
  demo/index.html
  original/Chatbot.py
```
